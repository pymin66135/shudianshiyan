# 这是一个简单的基于ARM架构的32位排序的内核，主要用于学习和实验。
## 我们的要求是在FPGA上用尽可能快的速度（更快的时钟频率以及更少的周期）来实现64个16位的数的排序。
> 为了实现这一目标，我们运用了许多技术，比如三级的pipeline和多核心的架构什么的，以及尝试了SIMO的技术等等。  
> 我们整体在程序的最外层套了一个状态机，来控制程序的流程，比如从固定的RAM里面读取数据以及在内核内部排序，将排序后的结果写入到RAM里面。
> 最后的成果是从120Mhz，5000多个时钟周期，压缩到150Mhz，300个时钟周期，其中有比较多的时钟周期浪费在了读和取上面，即使使用vivado里面的2路并行读取，也提升有限。
> 我们最后采用的排序方案是归并排序，然后是16核的方案，由于资源的限制，最后32核的方案因为综合时间太久，并且有可能vivado在中途报错，而放弃。
## 项目结构
>在src里面存放了我们的代码，这其中大部分都是AI生成的。然后就是其他的文件是一些vivado的项目文件。ALU以及Lab2_Countdown_Timer_Clean是我们前两个实验，mcu和simple_mcu_test是我们当前实验的代码。
